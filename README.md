# 网络新闻热度预测

期中：Python 数据分析，决策树、随机森林及调参评估。

期末：Spring Boot + MyBatis 网页，复用期中模型，MySQL 保存记录，Redis 缓存指标。

两个阶段在同一项目中衔接；个人信息不写入公开仓库。完整运行方法见两个文件夹内的说明。

数据来源：UCI Online News Popularity，https://archive.ics.uci.edu/dataset/332/online+news+popularity ，CC BY 4.0。原始文章版权属于 Mashable，本项目只使用公开统计特征。

首次运行 `期中Python/train.py` 自动下载数据并生成模型。数据、模型和报告随本地交付包提供，公开仓库保留代码、说明及分析结果。
